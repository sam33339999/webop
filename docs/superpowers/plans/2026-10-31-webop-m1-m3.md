# webop M1–M3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** opencode 透過 stdio MCP 啟動 `webop mcp`，經 Native Messaging 控制使用者 Chrome 中的 webop 擴充，在白名單網域上完成「導航 → `read_page` → 以 ref 或座標點擊 → 截圖」。

**Architecture:** `packages/core` 放協定型別與純函式（座標、預算、網域）。`apps/extension` 是 MV3 擴充，service worker 用 `chrome.debugger` 截圖與送輸入、content script 負責覆蓋層與 AX 樹。`apps/webop` 是一支 CLI：`native-host` 模式由 Chrome 拉起並在 per-profile Unix socket 上 listen，`mcp` 模式由 agent 拉起、連 socket、對外提供 MCP 工具。

**Tech Stack:** Node.js 26（原生 TS type stripping）、TypeScript 7（只做型別檢查）、pnpm workspaces、esbuild 0.28、`@modelcontextprotocol/sdk` 1.32、zod 4、tldts 7、`node:test`、Playwright 1.64（附帶 Chromium）。

**Spec:** `docs/superpowers/specs/2026-10-31-webop-design.md`（行為細節另見 `ANALYSIS.md` 第 2–5 節）。M4–M6 另立計畫。

## Global Constraints

- Node `>=26`（`package.json` 的 `engines`），以 `fnm install 26 && fnm use 26` 安裝；`.node-version` 寫 `26`。
- TS 只用可被 type stripping 處理的語法：tsconfig 開 `erasableSyntaxOnly`、`verbatimModuleSyntax`、`allowImportingTsExtensions`、`noEmit`；相對 import 一律帶 `.ts` 副檔名；不用 `enum`、namespace、parameter properties。
- 測試：`node --test`；不引入 Vitest/Jest。
- `packages/core` 不得 import 任何 `node:*` 或 `chrome.*`。
- 擴充 `minimum_chrome_version: "116"`；`manifest.json` 有固定 `key`。
- NM host 名稱：`com.webop.native_host`。
- 執行目錄：`~/.webop/run/`（`0700`），socket `~/.webop/run/<profile_id>.sock`（`0600`），描述檔 `~/.webop/run/<profile_id>.json`。
- MCP 工具名前綴 `browser_`；錯誤碼只能用 `packages/core/src/protocol.ts` 的 `ErrorCode`。
- 截圖預算預設 `{pxPerToken: 28, maxTargetPx: 1568, maxTargetTokens: 1568}`；JPEG quality 75；OOB 條件 `x<0 || y<0 || x>=screenshotWidth+2 || y>=screenshotHeight+2`。
- click 時序：mouseMoved → 等 100 ms → mousePressed → 12 ms → mouseReleased；多擊間隔 100 ms；滾輪 1 tick = 100 px。
- e2e 一律用 Playwright 附帶 Chromium + 暫存 `--user-data-dir`；**絕不在使用者日常 profile 跑自動化**。
- 參考原始碼資料夾 `fcoeoabgfenejglbffodgkkbkcdhcgfn/` 不得 import、不得複製程式碼。
- M3 授權最小版：只允許 `chrome.storage.local` 的 `webop.allow`（eTLD+1 陣列）內網域，其他一律 `permission_denied`。

## Review Focus

1. **Chrome 沒開／擴充沒載入時 agent 呼叫工具** → 回 `not_connected`，`webop mcp` 不退出；Chrome 起來後下一次呼叫自動成功。（Task 8 測試）
2. **已授權頁面點連結或被導向到未授權網域後再讀** → `read_page`、`screenshot` 以分頁目前網址重驗，回 `permission_denied`，不回內容。（Task 6 測試）
3. **上一次 host 當掉留下的 socket 檔** → 新 host 清掉殘檔並正常 listen；`webop mcp` 連到死 socket 時回 `not_connected` 而非掛住。（Task 7 測試）
4. **使用者按偵錯提示條「取消」** → 進行中呼叫回 `detached_by_user`，下一次呼叫自動重新 attach 成功。（Task 3 測試）
5. **導航後用舊 ref 點擊** → 回 `stale_ref`，不點到別的元素。（Task 5 測試）
