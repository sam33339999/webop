# 0.7.0 的取捨與已知代價

0.7.0 新增了讀取網路請求、讀取 console、GIF 錄影三個工具。實作過程中有幾件事需要取捨，這份文件列出每項的做法，以及使用者會遇到的影響。

設計依據：`docs/superpowers/specs/2026-11-02-console-network-gif-design.md`。

## 會直接感受到的變化

| 做法 | 代價 | 原因 |
|---|---|---|
| 建立分頁時先開 `about:blank`、附加 debugger，再導向目標網址 | 建立分頁時就會出現黃色的偵錯提示條，不再是第一次操作時才出現 | 不先附加的話，第一次載入時的網路請求會漏記 |
| console 等到第一次呼叫 `browser_read_console_messages` 才開始記錄 | 理論上看不到第一次讀取前的訊息（實測 Chrome 會補送，目前看得到） | `Runtime.enable` 會被反爬蟲腳本偵測，平常不開 |
| 使用者按停止後，從沒開過 console 記錄的分頁，第一次讀 console 仍會重新附加 debugger | 按停止後，提示條可能因為這次讀取又出現一次 | 這和停止後再做任何操作的行為一樣；已經開過 console 記錄的分頁不會因為讀取而重新附加 |
| 附加 debugger 時，頁面 2.5 秒內沒回應就當作有對話框開著 | 頁面剛被接手時，如果正在跑很重的腳本，會誤報「有對話框開著」；頁面回應後就恢復正常 | 頁面已經開著 `alert` 時，Chrome 不會通知，舊做法會整個卡住直到逾時 |

## 遮蔽：寧可多遮

| 做法 | 代價 |
|---|---|
| 參數名稱以 token、secret、key、code、pass、sig、session 等結尾就遮蔽 | `zipcode`、`country_code`、`monkey`、`design` 這類無害參數也會顯示成 `REDACTED` |
| 網址解析失敗時，照樣遮蔽查詢參數和帳號密碼 | 格式怪異的網址可能被遮得比預期多 |
| console 的 stack 網址整段遮蔽 | 被遮的網址後面的 `:行:欄` 會一起消失 |
| 網址路徑裡的值不遮（例如 `/reset/<token>`） | 放在路徑裡的憑證仍會出現；設計文件只要求遮帳號密碼、查詢參數和 `#` 後面的參數 |

## 讀取工具

| 情況 | 行為 | 代價 |
|---|---|---|
| 分頁導向別的網站（eTLD+1 不同） | 兩種紀錄都清空 | 同一個網站不同子網域（例如 `a.example.com` → `b.example.com`）不會清空 |
| 分頁正要導向本 session 不能讀的網站 | 回 `permission_required` | 剛好導向 `chrome://` 頁面或觸發下載的那一瞬間讀取，可能回一次權限錯誤 |
| `url_pattern` | 子字串比對，不分大小寫 | 不能用正規表示式 |
| `pattern`（console） | 正規表示式，最多 200 字元 | 太長的式子會被拒絕，回 `invalid_pattern` |
| 重新附加時，啟用 console 的指令逾時 | 這次不記錄，下次讀取時重新啟用 | 回應可能再出現一次「Console recording started now」 |
| `throw "字串"` 這類不是 Error 的例外 | 只看得到 `Uncaught`，看不到丟出的值 | 除錯時資訊較少 |

## GIF

| 做法 | 代價 |
|---|---|
| 點擊標記畫在動作之前的那一格 | 第一格和新分頁的第一格是動作之後拍的，所以不畫圈，只有文字說明 |
| 捲動、滑鼠移入有座標時也畫圈 | 捲動的格子會多一個紅圈 |
| 按鍵說明最多 20 個字元，打字只顯示字數 | agent 若用按鍵一個一個打字，前 20 個字元會出現在說明裡 |
| 匯出後畫面保留，到 `clear` 或下次開始錄影才清掉 | 匯出後最多 50 張畫面繼續佔記憶體 |
| 匯出時不重新檢查網站權限 | 同一個 session 內，已撤銷授權的網站畫面仍會被匯出（畫面錄下時是有權限的） |
| 畫面本身不做遮蔽 | 只保證說明列不顯示輸入內容；頁面上看得到的內容（包括剛輸入的明文欄位）會拍進 GIF |
| 50 格、1280 寬的編碼在擴充功能裡進行 | 實測每格約 0.46 秒，50 格約 25 秒；仍在 60 秒呼叫上限內，但很慢 |
| 錄影時 `navigate`／`tabs_create` 會多拍一張 | 這次呼叫剩不到 10 秒就略過，那一步不會有畫面 |
| `WEBOP_GIF_DIR` 可改存放位置 | 只有 Chrome 帶著這個環境變數啟動才生效；從 Dock 開的 Chrome 不會繼承 shell 的設定 |
| 檔名上限 200 bytes | 中文檔名大約 60 個字就會被截斷 |

## 不處理的範圍

- 跨網站 iframe（OOPIF）和 worker 的 console／網路請求收不到。
- service worker 重啟後，記錄和 console 開啟狀態都會遺失，要等下次操作那個分頁才恢復。
