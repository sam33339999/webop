1. `fnm use 26`（`node --version` 要是 v26）
2. `pnpm install && pnpm -r build`，在 `chrome://extensions` 重新載入擴充功能（卡片顯示 0.7.0），執行 `webop doctor` 確認全部 `ok`。
3. 準備一個「按鈕按了沒反應」的測試頁（例如按下去會打一個失敗的 fetch 並寫 console.error）。
